# El embudo del negocio

Fuente única del ciclo completo, de "salir a buscar" hasta "el cliente nos recomienda".
[`MOTOR.md`](../MOTOR.md) lo resume y apunta acá.

> **Idea rectora (de Gaby):** a un cliente nuevo **primero le mostramos un prototipo para que lo
> toque, y después profundizamos.** El prototipo es el gancho; sale del quick win de mayor impacto
> del mapa de oportunidades.

---

## Pre-embudo: salir a buscar

```
BUSCAR empresas con un hueco        <- skill `buscar-clientes`
  -> DIAGNÓSTICO (interno)           <- skill `diagnostico-digital`
    -> Primer contacto               (lo manda Gaby, de a uno)
      -> Charla
```

También se entra por boca en boca o por un trabajo nuestro. Al prospecto se le ofrece una
propuesta concreta y 15 minutos de videollamada, no "un diagnóstico gratis".

## Embudo del proyecto (prototipo primero)

```
CLIENTE NUEVO: contexto + auditoría           <- skill `cliente-nuevo`
  -> MAPA DE OPORTUNIDADES (analisis.md)       <- `cliente-nuevo` cruza con 01-Capacidades
    -> PRIMER PROTOTIPO para mostrar           <- el quick win de mayor impacto, rápido y tocable
      -> MOSTRAR al cliente + feedback
        -> PROFUNDIZAR
          -> BRIEF                             <- `brief-cliente`
            -> PROPUESTA + precio              <- `propuesta-comercial` (grilla de 03-Comercial)
              -> Seña / OK
                -> CONSTRUCCIÓN                <- `construir-web` u otra capacidad
                  -> REVISIÓN (1 ronda incluida)
                    -> PUBLICACIÓN + entrega   <- `publicar-web`
                      -> MANTENIMIENTO mensual  <- la plata que se repite
                        -> REFERIDO
```

## Dónde se pierden los negocios, en orden

1. **Esperar a que aparezca el cliente.** Por eso existen `buscar-clientes` y el diagnóstico: se
   sale a buscar con un hallazgo útil en la mano y se ofrece una propuesta concreta.
2. **Mostrar un PDF en vez de un prototipo que se toca.** Un documento de 10 páginas no convence
   a nadie; algo andando en el celular del dueño, sí. El prototipo vende; el documento confirma.
3. **Brief flojo** → se construye lo que no era, hay retrabajo, se come la ganancia.
4. **Ida y vuelta infinito** de cambios → se pactan **rondas de revisión**, no cambios ilimitados.
5. **El cliente nunca manda el material** (textos, fotos, logo) → la obra queda a medias. Por eso
   el agente **escribe los textos** y usa placeholders profesionales desde el día 1.
6. **Se entrega y chau** → sin mantenimiento no hay negocio, hay changas.

## Reglas del embudo

- El agente prepara; **manda Gaby**. Nada sale a un prospecto ni a un cliente sin su OK.
- Los precios salen solo de `03-Comercial/precios.md`.
- Cada etapa deja su archivo en la carpeta del proyecto del cliente (`C:/Claude/Clientes/<cliente>/`)
  o del prospecto (`04-Prospectos/<empresa>/`, en el Estudio), nunca suelto.
